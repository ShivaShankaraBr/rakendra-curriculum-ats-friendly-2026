# Prompt final utilizado no Lovable

```markdown
Crie um aplicativo web responsivo chamado Rakendra Curriculum ATS Friendly 2026.

É um MVP acadêmico para ajudar uma pessoa a comparar seu currículo com uma vaga de emprego e gerar uma versão mais compatível com sistemas ATS.

Use React, TypeScript, Tailwind CSS e shadcn/ui. Não crie login, cadastro, banco de dados, integrações externas ou cobrança. O usuário deve entrar e usar imediatamente.

Use a identidade visual Rakendra: grafite escuro, marfim, dourado/cobre e verde suave como cores principais. Use azul discreto e amarelo-claro somente em pequenos detalhes de informação e destaque. O visual deve ser profissional, limpo, elegante e acolhedor. Use o logo oficial da Rakendra que anexarei, sem alterar o desenho e preservando a lua cheia.

Crie uma experiência em uma única página, organizada por etapas:

Tela inicial com o título “Rakendra Curriculum ATS Friendly 2026”, a frase “Seu currículo merece dar match com a vaga, não tomar ghosting do ATS” e o botão “Começar análise”.

Área com dois campos grandes:

“Meu currículo ou perfil profissional”

“Descrição da vaga desejada”

Inclua botão “Usar exemplo” para preencher os campos com dados fictícios de demonstração e botão “Analisar compatibilidade”.

Após a análise, mostrar:

pontuação de compatibilidade ATS de 0 a 100 em indicador circular ou barra;

status “Match forte”, “Bom potencial” ou “Risco de ghosting pelo ATS”;

palavras-chave encontradas;

palavras-chave ausentes;

competências compatíveis;

recomendações práticas e claras.

A análise pode ser simulada localmente comparando palavras e termos entre currículo e vaga. Deixe claro que é uma estimativa educativa e não uma garantia de contratação.

Criar abaixo uma área “Currículo ATS Friendly” que gere uma versão editável do currículo com:

nome e contatos;

objetivo profissional;

resumo profissional;

competências;

experiências;

formação;

cursos e certificações.

Nunca invente experiências, empresas, cursos, habilidades ou resultados. Use somente os dados informados ou deixe campos editáveis para completar.

Adicionar botões funcionais:

“Copiar currículo”

“Exportar currículo em PDF”

“Nova análise”

A exportação deve gerar um PDF simples, em uma coluna, fundo branco, texto escuro e estrutura fácil de ler por ATS. Não usar layout em duas colunas, tabelas complexas ou elementos decorativos dentro do currículo.

No rodapé, incluir acesso a um modal “Design System” mostrando logo, paleta de cores, tipografia, botões, campos, cartões e indicadores. Adicionar botão “Exportar Design System em PDF”.

Deixe o aplicativo pronto para demonstração, com excelente visual em desktop e celular, campos validados, mensagens amigáveis e sem botões sem função.

Anexe o logo da Rakendra antes de enviar. Depois disso, não faça novos pedidos ao Lovable até ele terminar e você me mandar o preview, porque vamos analisar o resultado antes de gastar qualquer crédito restante.
```

O prompt foi deliberadamente enxuto para concentrar os créditos gratuitos do Lovable em um MVP demonstrável.
